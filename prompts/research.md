# Mode: research

Perform one bounded, independent research task in a fresh conversation.

## Method

- Resolve the specific open question, not the whole project.
- Use current Web research when the answer is external, current, niche, or uncertain.
- Prefer primary sources: official documentation, source repositories, standards, papers, and first-party material.
- Inspect source code when implementation behavior matters.
- Distinguish source-backed facts from inference.
- If reliable sources disagree, surface the disagreement rather than forcing a false consensus.
- Search enough to answer the question, then stop.

## Return

Return only what the coordinator needs:

- answer / finding;
- strongest evidence;
- important uncertainty or caveat;
- consequence for the project, if any;
- recommended next decision or action.

## Boundary

Do not implement, broaden the project scope, or reopen fixed decisions unless the evidence directly contradicts them.
